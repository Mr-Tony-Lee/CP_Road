# LeetCode 3693. Climbing Stairs II

## 1. 題目概念

樓梯共有從 `0` 到 `n` 的 `n + 1` 個階梯。從第 `i` 階只能跳到第 `i + 1`、`i + 2` 或 `i + 3` 階；跳到第 `j` 階的成本為：

$$
cost[j] + (j - i)^2
$$

其中 `cost` 為長度 `n` 的陣列，`cost[j]` 對應第 `j + 1` 階的成本。起點為第 `0` 階、初始成本為 `0`，求到達第 `n` 階的最小總成本。

## 2. 解題策略：動態規劃

定義：

$$
dp[i] = \text{到達第 } i \text{ 階的最小總成本}
$$

到達第 `i` 階時，前一步只可能來自第 `i - 1`、`i - 2` 或 `i - 3` 階，三種跳躍距離的額外成本分別為 $1^2 = 1$、$2^2 = 4$、$3^2 = 9$。

因此，對於 $i \ge 3$：

$$
dp[i] = cost[i-1] + \min(dp[i-1] + 1,\; dp[i-2] + 4,\; dp[i-3] + 9)
$$

初始狀態為：

$$
dp[0] = 0
$$

由於每個狀態只依賴前三個狀態，程式以 `dp_0`、`dp_1`、`dp_2` 滾動保存，將空間最佳化為常數。

## 3. 演算法步驟

1. 設定 `dp_0 = 0`，代表位於第 `0` 階的成本。
2. 計算到達第 `1`、第 `2` 階的初始狀態。
3. 從第 `3` 階開始，依遞推式計算目前最小成本。
4. 每完成一階，將三個滾動變數往前更新。
5. 回傳到達第 `n` 階的最小成本。

## 4. 範例說明

```text
n = 4
cost = [1, 2, 3, 4]
```

其中一條最佳路徑為 `0 → 1 → 2 → 4`：

| 跳躍 | 成本計算 | 成本 |
|------|----------|------|
| 0 → 1 | `1 + 1²` | 2 |
| 1 → 2 | `2 + 1²` | 3 |
| 2 → 4 | `4 + 2²` | 8 |

總成本為 `2 + 3 + 8 = 13`，因此答案為 `13`。

## 5. 複雜度分析

- 時間複雜度：$O(n)$，每一階只計算一次。
- 空間複雜度：$O(1)$，僅保留前三個 DP 狀態。

## 7. 注意事項

- `cost[i - 1]` 對應第 `i` 階的落腳成本，因為 `cost` 在 C++ 中是 0-indexed。
- 跳 1、2、3 階時的距離成本分別是 `1`、`4`、`9`。
- 題目要求的是最小總成本，因此每一步都須從三個可達前一狀態中取最小值。
