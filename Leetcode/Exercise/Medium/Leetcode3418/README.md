# LeetCode 3418. Maximum Amount of Money Robot Can Earn

## 1. 核心思維：動態規劃 (Dynamic Programming)

這是一個路徑優化問題，機器人從 $(0, 0)$ 出發只能向右或向下移動，目標是到達 $(m-1, n-1)$。每個格子可能有收益或損失，核心挑戰在於機器人擁有 **最多兩次中和強盜（使其負值收益變為 0）** 的特殊能力。

為了追蹤當前使用了多少次中和機會，我們採用三維動態規劃，定義 $dp[i][j][k]$ 為到達格子 $(i, j)$ 且目前已消耗了 $k$ 次中和機會時所能獲得的最大利潤，其中 $k \in \{0, 1, 2\}$。

## 2. 解題策略：狀態紀錄與條件轉移

### 狀態定義
- `dp[i][j][0]`：尚未執行任何中和。
- `dp[i][j][1]`：已經執行過 1 次中和。
- `dp[i][j][2]`：已經執行過 2 次中和。

### 轉移邏輯
機器人只能從上方 $(i-1, j)$ 或左方 $(i, j-1)$ 移動過來。對於每一個格子 $(i, j)$，我們取這兩個來源的最大值作為基礎。

1. **零次中和**：直接加上當前格子的值。
2. **一次中和**：
   - 若當前格子 $coins[i][j] \ge 0$，正常累加。
   - 若當前格子 $coins[i][j] < 0$：
     - 選擇不在此處中和：保持之前的 1 次中和狀態加上當前負值。
     - 選擇在此處中和：從之前的 0 次中和狀態轉移過來，且當前收益視為 0。
3. **二次中和**：
   - 同理，若 $coins[i][j] < 0$：
     - 選擇不在此處中和：保持之前的 2 次中和狀態加上當前負值。
     - 選擇在此處中和：從之前的 1 次中和狀態轉移過來，且當前收益視為 0。

## 3. 演算法步驟

1. **建立三維 DP 表**：大小為 $m \times n \times 3$，並根據起點 $(0, 0)$ 初始化（若 $coins[0][0] < 0$，則 $k=1, 2$ 時的價值均可為 0）。
2. **邊界預處理**：
   - 填充第一行與第一列，因其路徑來源唯一。
3. **全局填充**：
   - 使用雙層迴圈處理其餘格點。
   - 每次移動取 `max(up, left)`。
   - 根據強盜情況判定是否更新中和次數後的數值。
4. **取得答案**：
   - 到達 $(m-1, n-1)$ 後，取 $k=0, 1, 2$ 三個狀態中的最大值。

### 複雜度分析

- **時間複雜度**：$O(M \times N)$。我們僅需要遍歷網格一次，每個格子的計算量為常數級（處理 3 種 `k` 狀態）。
- **空間複雜度**：$O(M \times N)$。使用了與網格大小成比例的三維空間（$M \times N \times 3$）。
