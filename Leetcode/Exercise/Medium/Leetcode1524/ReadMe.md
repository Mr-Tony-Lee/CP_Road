# LeetCode 1524. Number of Sub-arrays With Odd Sum

## 1. 題目概念

給定整數陣列 `arr`，計算其中總和為奇數的連續子陣列數量。由於答案可能很大，最後要對 $10^9 + 7$ 取模。

例如：

```text
arr = [1, 3, 5]
```

所有連續子陣列及其總和：

```text
[1] = 1       → 奇數
[3] = 3       → 奇數
[5] = 5       → 奇數
[1, 3] = 4    → 偶數
[3, 5] = 8    → 偶數
[1, 3, 5] = 9 → 奇數
```

因此答案為 `4`。

## 2. 解題想法：奇偶性 + 動態規劃

令 `prev_res` 表示「以前一個位置結尾、總和為奇數的子陣列數量」。當處理 `arr[i]` 時，只需要根據目前元素的奇偶性更新它。

### 當 `arr[i]` 為偶數

在任何既有子陣列尾端加上一個偶數，不會改變總和的奇偶性。

因此，以 `i` 結尾的奇數和子陣列數量，與前一個位置結尾的數量相同：

$$
odd_i = odd_{i-1}
$$

### 當 `arr[i]` 為奇數

在一個偶數和子陣列尾端加上奇數，總和會變成奇數；此外，單獨的 `arr[i]` 也是一個奇數和子陣列。

在索引 `i` 之前，共有 `i` 個非空、以前一個位置結尾的子陣列。其中 `prev_res` 個為奇數和，所以偶數和子陣列數量為：

$$
i - prev\_res
$$

故新的奇數和子陣列數量為：

$$
odd_i = (i - prev\_res) + 1
$$

最後的 `+1` 代表只包含 `arr[i]` 的子陣列。

## 3. 演算法步驟

1. 初始化 `prev_res = 0` 與 `ans = 0`。
2. 從左到右遍歷陣列的每個元素 `arr[i]`：
   - 若 `arr[i]` 是奇數，更新 `prev_res = i - prev_res + 1`。
   - 若 `arr[i]` 是偶數，`prev_res` 維持不變。
3. 將目前以 `i` 結尾的奇數和子陣列數量 `prev_res` 累加到 `ans`。
4. 每次累加後對 $10^9 + 7$ 取模。
5. 回傳 `ans`。

## 4. 範例說明

```text
arr = [1, 2, 3]
```

| i | arr[i] | 以 i 結尾的奇數和子陣列 | prev_res | ans |
|---|--------|--------------------------|----------|-----|
| 0 | 1      | `[1]`                    | 1        | 1   |
| 1 | 2      | `[1, 2]`                 | 1        | 2   |
| 2 | 3      | `[3]`、`[2, 3]`          | 2        | 4   |

答案為 `4`。

## 5. 複雜度分析

- 時間複雜度：$O(n)$，只需線性遍歷一次陣列。
- 空間複雜度：$O(1)$，只使用 `prev_res` 與 `ans` 等常數額外空間。

## 7. 注意事項

- C++ 中可使用 `arr[i] & 1` 判斷元素是否為奇數。
- `prev_res` 是「目前位置結尾」的數量，不是目前累積的總答案。
- 答案必須依題意對 $10^9 + 7$ 取模。
