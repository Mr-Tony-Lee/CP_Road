# LeetCode 2075. Decode the Slanted Ciphertext

## 1. 核心思維：二維矩陣與斜向遍歷

這道題目要求我們解出一種「斜向加密」的字串。加密過程中，原始字串被填入一個指定列數 (`rows`) 的矩陣中，然後按列讀取形成加密後的字串。解密時，我們需要先將加密字串還原回矩陣，然後沿著對角線的方向（斜向）讀取出原始訊息。

## 2. 解題策略：矩陣還原與對角線讀取

### 1. 計算矩陣維度
加密字串的長度 $n$ 等於 `rows * cols`，因此我們可以先求出列數 `cols = n / rows`。

### 2. 還原矩陣
將加密字串 `encodedText` 填回一個 `rows x cols` 的二維矩陣（或直接利用一維字串的索引關係來模擬二維存取）。
- `encodedText[i * cols + j]` 對應矩陣中第 `i` 列、第 `j` 行的字元。

### 3. 斜向讀取
原始訊息是從對角線開始讀取的：
- 第一條對角線從 $(0, 0) \to (1, 1) \to (2, 2) \dots$ 開始。
- 第二條對角線從 $(0, 1) \to (1, 2) \to (2, 3) \dots$ 開始。
- 依此類推，最左上角的起始點為 $(0, \text{first\_j})$，其中 `first_j` 從 $0$ 到 `cols - 1`。

### 4. 去除尾隨空白
題目提到原始訊息後面可能有空白字元，但在加密時為了填滿矩陣增加了額外的空白。解密後需要將字串末尾多出的空白刪除，但中間的空白必須保留。

## 3. 演算法步驟

1. **處理特殊情況**：
   - 若 `rows == 1` 或字串為空，直接回傳 `encodedText`。
2. **建立矩陣**：
   - 根據 `rows` 和 `cols` 將 `encodedText` 轉換為二維矩陣 `mat`。
3. **遍歷與收集**：
   - 使用變數 `first_j` 標記每一斜列的起始行。
   - 在迴圈中，沿著 `(i++, j++)` 的方向收集字元。
   - 當 `i` 達到 `rows` 或 `j` 達到 `cols` 時，回到第一列 (`i = 0`) 並將 `first_j` 加 1，從下一斜列開始。
4. **尾端處理**：
   - 從收集到的 `ans` 字串末尾開始往前檢查，移除所有連續的空白字元，直到遇到第一個非空白字元為止。
5. **回傳結果**。

### 複雜度分析

- **時間複雜度**：$O(N)$。其中 $N$ 是加密字串的長度。建立矩陣需要 $O(N)$，斜向讀取也會遍歷矩陣中大部分字元，最後去除空白也是線性操作。
- **空間複雜度**：$O(N)$。需要一個 $O(N)$ 的空間來儲存矩陣以及最後生成的結果字串。
