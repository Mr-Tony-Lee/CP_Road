# LeetCode 2840. Check if Strings Can be Made Equal With Operations II

## 1. 核心思維：奇偶位元獨立性

這題的核心在於觀察交換操作的限制：我們只能交換距離為 **偶數** 的兩個下標 `i` 和 `j`（即 `j - i` 為偶數，意味著 `i` 與 `j` 的奇偶性相同）。
這意味著：
- 下標為 **偶數** 的字元只能與下標為 **偶數** 的字元交換位置。
- 下標為 **奇數** 的字元只能與下標為 **奇數** 的字元交換位置。

因此，如果 `s1` 可以經由這類交換變成 `s2`，則：
1. `s1` 中所有偶數下標位置的字元集合，必須與 `s2` 中所有偶數下標位置的字元集合完全相同。
2. `s1` 中所有奇數下標位置的字元集合，必須與 `s2` 中所有奇數下標位置的字元集合完全相同。

## 2. 解題策略：次數統計 (Counting)

由於我們只需判斷字元集合是否相同（包含各字元的出現次數），我們可以使用計數器來紀錄頻率：
- `r1` (奇數位置計數)：紀錄奇數索引下標處的字元頻率差異。
- `r2` (偶數位置計數)：紀錄偶數索引下標處的字元頻率差異。

我們同時遍歷字串 `s1` 和 `s2`：
- 對於每一個索引 `i`：
    - 如果 `i` 是奇數，我們增加 `s1[i]` 的計數並減少 `s2[i]` 的計數。
    - 如果 `i` 是偶數，我們增加 `s1[i]` 的計數並減少 `s2[i]` 的計數。

遍歷結束後，如果 `r1` 和 `r2` 中的所有字母出現次數皆歸零，代表兩字串在對應位元（奇數位或偶數位）上的字元組成完全一致，可以互相轉換。

## 3. 演算法步驟

1. 初始化兩個大小為 26 的整數陣列 `r1` 與 `r2`，初始值皆為 0。
2. 使用迴圈從 `i = 0` 遍歷到 `n - 1`：
   - 若 `i` 為奇數 (`i & 1`)：執行 `r1[s1[i]-'a']++` 與 `r1[s2[i]-'a']--`。
   - 若 `i` 為偶數：執行 `r2[s1[i]-'a']++` 與 `r2[s2[i]-'a']--`。
3. 檢查 `r1` 與 `r2` 中所有 26 個索引：
   - 若有任何元素不等於 0，表示字元分布不匹配，回傳 `false`。
4. 若所有元素皆為 0，回傳 `true`。

### 複雜度分析

- **時間複雜度**：$O(N)$。我們僅需遍歷一次長度為 $N$ 的字串，後續檢查固定大小 (26) 的陣列時間可忽略不計。
- **空間複雜度**：$O(1)$。我們使用了兩個固定大小為 26 的陣列，儲存空間不隨輸入字串長度 $N$ 而改變。
