# LeetCode 3105. Longest Strictly Increasing or Strictly Decreasing Subarray

## 1. 題目概念

給定整數陣列 `nums`，找出最長的連續子陣列，使其元素嚴格遞增或嚴格遞減。

「嚴格」代表相鄰元素不能相等：

```text
遞增：nums[i] > nums[i - 1]
遞減：nums[i] < nums[i - 1]
```

例如：

```text
nums = [1, 4, 3, 3, 2]
```

- `[1, 4]` 為嚴格遞增，長度為 `2`。
- `[4, 3]` 為嚴格遞減，長度為 `2`。
- 兩個 `3` 相等，不能出現在同一個嚴格單調子陣列中。

因此答案為 `2`。

## 2. 解題策略：線性掃描

使用兩個變數記錄目前位置結尾的最長單調子陣列長度：

- `inc`：目前嚴格遞增區段的長度。
- `dec`：目前嚴格遞減區段的長度。

從左到右比較 `nums[i]` 與 `nums[i - 1]`：

1. 若 `nums[i] > nums[i - 1]`，遞增區段可以延續，`inc++`；遞減區段中斷，`dec = 1`。
2. 若 `nums[i] < nums[i - 1]`，遞減區段可以延續，`dec++`；遞增區段中斷，`inc = 1`。
3. 若兩者相等，兩種嚴格單調區段都中斷，`inc = dec = 1`。
4. 每次更新後，以 `inc`、`dec` 更新全域答案 `ans`。

## 3. 範例說明

```text
nums = [3, 2, 1, 4]
```

| 目前元素 | 關係 | inc | dec | 最長長度 |
|----------|------|-----|-----|----------|
| 3        | 起點 | 1   | 1   | 1        |
| 2        | 遞減 | 1   | 2   | 2        |
| 1        | 遞減 | 1   | 3   | 3        |
| 4        | 遞增 | 2   | 1   | 3        |

最長的嚴格遞減子陣列是 `[3, 2, 1]`，答案為 `3`。

## 4. 複雜度分析

- 時間複雜度：$O(n)$，只需走訪陣列一次。
- 空間複雜度：$O(1)$，只使用固定數量的變數。

## 6. 注意事項

- 單一元素本身也是合法的嚴格單調子陣列，長度為 `1`。
- 相鄰元素相等時，不能延續遞增或遞減區段。
- 只需比較相鄰元素，不需要列舉所有子陣列。
