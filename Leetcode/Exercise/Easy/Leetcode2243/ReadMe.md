# LeetCode 2243. Calculate Digit Sum of a String

## 1. 題目概念

給定一個由數字字元組成的字串 `s` 與整數 `k`。只要 `s` 的長度大於 `k`，就將字串從左到右切成每組至多 `k` 個字元的區段，計算每組所有數字的總和，並把各組總和依序串接成新的字串。

重複此操作，直到字串長度不大於 `k`，回傳最後的字串。

例如：

```text
s = "11111222223", k = 3
```

第一次分組與轉換：

```text
"111" → 3
"112" → 4
"222" → 6
"23"  → 5
```

得到 `"3465"`；接著轉換為 `"132"`，長度已等於 `k`，因此答案是 `"132"`。

## 2. 解題策略：模擬分組轉換

依題意直接模擬即可。每一輪處理時：

1. 建立空字串 `res` 儲存下一輪結果。
2. 以間隔 `k` 走訪 `s`，每次取得一個長度最多為 `k` 的區段。
3. 將區段中的每個字元轉為數字後累加。
4. 用 `to_string(sum)` 將總和接到 `res` 後方。
5. 將 `s` 更新成 `res`，直到 `s.size() <= k`。

## 3. 範例說明

```text
s = "00000000", k = 3
```

第一輪：

```text
"000" → 0
"000" → 0
"00"  → 0
```

結果為 `"000"`，長度為 `3`，停止轉換並回傳 `"000"`。

## 4. 複雜度分析

- 時間複雜度：$O(n \times t)$，其中 `n` 為初始字串長度、`t` 為轉換輪數；每輪最多走訪目前字串一次。
- 空間複雜度：$O(n)$，用於建立每一輪的結果字串。

## 6. 注意事項

- 最後一組的長度可能小於 `k`，仍須計算其數字總和。
- 字元數字可用 `s[j] - '0'` 轉成整數。
- 每組的總和可能超過一位數，所以必須使用 `to_string` 串接結果。
