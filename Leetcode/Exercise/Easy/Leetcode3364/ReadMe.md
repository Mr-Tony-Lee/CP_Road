# LeetCode 3364. Minimum Positive Sum Subarray

## 1. 題目概念

給定整數陣列 `nums` 與兩個整數 `l`、`r`，找出所有長度介於 `l` 和 `r`（含）之間的連續子陣列中，**總和嚴格大於 0** 的最小總和。

若不存在總和為正數的合法子陣列，回傳 `-1`。

例如：

```text
nums = [3, -2, 1, 4], l = 2, r = 3
```

長度為 2 或 3 的子陣列總和如下：

```text
[3, -2]      = 1
[-2, 1]      = -1
[1, 4]       = 5
[3, -2, 1]   = 2
[-2, 1, 4]   = 3
```

其中最小的正數總和為 `1`。

## 2. 解題想法：Prefix Sum + 枚舉長度

題目中的陣列長度不大，因此可以直接枚舉所有可能的子陣列長度，以及每個長度對應的起點。

為了快速取得每個子陣列的總和，先建立前綴和陣列 `pref`：

```text
pref[i] = nums[0] + nums[1] + ... + nums[i - 1]
```

若子陣列範圍為 `[start, end]`，其總和可在 $O(1)$ 時間內算出：

$$
sum(start, end) = pref[end + 1] - pref[start]
$$

接著：

1. 枚舉子陣列長度 `k`，範圍為 `l` 到 `r`。
2. 枚舉每個長度為 `k` 的合法起點 `start`。
3. 以前綴和取得該子陣列總和。
4. 若總和大於 `0`，用它更新答案。
5. 若最後答案仍未被更新，回傳 `-1`。

## 3. 範例說明

```text
nums = [-1, 2, -3, 4]
l = 2, r = 3
```

可檢查的子陣列：

```text
長度 2：[-1, 2] = 1、[2, -3] = -1、[-3, 4] = 1
長度 3：[-1, 2, -3] = -2、[2, -3, 4] = 3
```

符合條件的總和為 `1`、`1`、`3`，因此答案為 `1`。

## 4. 複雜度分析

- 時間複雜度：$O(n \times (r-l+1))$，其中 `n` 為 `nums` 的長度。
- 空間複雜度：$O(n)$，用於儲存前綴和陣列。

## 5. C++ 實作

對應程式碼請見 [Leetcode3364.cpp](Leetcode3364.cpp)。

實作時，長度為 `k` 的子陣列起點必須包含最後一個合法位置，因此迴圈條件應涵蓋 `start <= n - k`；使用一維前綴和時可寫成：

```cpp
for (int start = 0; start + k <= n; ++start) {
    int sum = pref[start + k] - pref[start];
    if (sum > 0) ans = min(ans, sum);
}
```

## 6. 注意事項

- 題目要求的是「正數」，所以總和等於 `0` 時不能更新答案。
- 子陣列必須是連續的，不能任意挑選元素。
- 當沒有任何合法的正數總和時，回傳 `-1`。
