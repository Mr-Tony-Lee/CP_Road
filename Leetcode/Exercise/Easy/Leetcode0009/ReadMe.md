# LeetCode 9. Palindrome Number

## 1. 核心思維：數字反轉 (Number Reversal)

我們的目標是判斷一個整數是否為「回文數」，即正讀和反讀都相同的數字。

最直觀的特點：
- **負數**：由於帶有負號（例如 `-121` 反轉後為 `121-`），所有的負數皆非回文數。
- **正數**：我們將數字進行反轉，若反轉後的數值與原數值相等，則該數為回文數。

## 2. 解題策略：反轉數值並比較

### 處理溢位問題
在反轉數字的過程中，反轉後的數值可能會超過 32 位元整數 (`int`) 的範圍。為了確保計算安全，我們使用 `long long` 型態來存儲反轉後的結果 `rev`。

### 判斷邏輯
1. **負數排除**：若 $x < 0$，直接回傳 `false`。
2. **反轉計算**：透過餘數運算 `% 10` 取得最後一位數，並透過除法 `/ 10` 移除最後一位數，逐步建構反轉後的數字。
3. **比較結果**：檢查 `rev == x` 是否成立。

## 3. 演算法步驟

1. **特殊情況判斷**：
   - 如果 $x < 0$，回傳 `false`。
2. **初始化**：
   - 建立變數 `temp` 紀錄原始值（供循環處理用）。
   - 建立變數 `rev` 並初始化為 `0`。
3. **執行反轉**：
   - 當 `temp > 0` 時：
     - `rev = rev * 10 + temp % 10`。
     - `temp = temp / 10`。
4. **回傳結果**：
   - 回傳 `rev == x` 的布林值。

### 複雜度分析

- **時間複雜度**：$O(\log_{10} N)$。迴圈執行的次數取決於數字的位數，對於數值 $N$，位數約為 $\log_{10} N$。
- **空間複雜度**：$O(1)$。我們僅使用了常數個額外變數。
